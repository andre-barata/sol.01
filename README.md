# sol.01

So this is my first cyberdeck. i got inspired by [u/nilseuropa](https://www.reddit.com/user/nilseuropa/) 's cases for the ESP32-S3-RLCD-4.2 and Rii 518bt keyboard, and also wanted to try changing to a 10000 mAh battery and see how long it would last, also made both the keyboard and ESP kit use the same battery, and rerouted the keyboard pair switch.

it uses no glue or screws, its snap-fit, tried keeping it thin and light as possible. But the mod on the hardware need some soldering and removing some parts as you can tell.

As for the battery, its the first full charge I'm doing, so it's too early to tell, I'm thinking it should last more than a week at least (always on), or more using stand-by when not needed

Parts Used:
 - Waveshare kit [https://www.waveshare.com/esp32-s3-rlcd-4.2.htm]
 - Rii 518BT
 - 1260110 Lithium battery [https://pt.aliexpress.com/item/1005012942890060.html]
